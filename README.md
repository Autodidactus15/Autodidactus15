## Рабочие направления

- Финансовые модели для расчёта CPS (Cost per Sale) и распределения бюджета реферальной программы с учётом прогноза спроса.

- Продуктовые и риск-метрики: retention, LTV/CAC, PD/LGD/EAD, винтажи, ROC-AUC/Gini и PSI.
